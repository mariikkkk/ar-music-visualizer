## КТ2 — аналитический этап

Консольная версия рассчитывает спектр звука, RMS, спектральный центроид,
яркость и оттенок визуализации. Язык — Python 3.14.7, только стандартная
библиотека. Данные семи сущностей хранятся в JSON.

```bash
cd src
python3 main.py demo
python3 checks.py
```

Пример сам создаёт короткий WAV. Инструкция и ожидаемый вывод находятся
в [src/README.md](src/README.md). Собственных классов в программе нет.

Модели лежат в [models](models): BPMN, логическая ER-модель и две блок-схемы.
Каждая модель сохранена исходником и PNG. BPMN описывает один процесс
с двумя дорожками: слушателя и приложения. На КТ2 реализована его вычислительная
часть; размещение и показ объектов относятся к мобильному приложению.

Отчёты по контрольным точкам находятся в папке [report](report).
