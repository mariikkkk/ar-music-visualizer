# AR-визуализатор. Расчёт сопровождения на Java

Проверено на Temurin JDK 25.0.4.1. Исходники совместимы с Java 17. Сборка через Gradle 9 (для запуска Gradle нужен JDK 17 или новее). Единственная библиотека приложения — Gson 2.13.1 для обмена данными с процедурной версией.

Из каталога src/java выполните:

    gradle build
    gradle run --args="example/input.json output/result.json"

При первом запуске Gradle скачивает зависимости из Maven Central. В example лежат входной JSON и несжатый монофонический WAV PCM 16 бит. Для выбора записей передайте после путей идентификаторы трека, профиля и пресета, например 1 1 1. Пути к WAV считаются от каталога входного JSON. При повторном анализе перенесите WAV рядом с новым входом или обновите source_uri.

Синус 1000 Гц при частоте дискретизации 8000 Гц, кадр 256 отсчётов и шаг 128 дают следующий результат:

    Анализ: 1; сеанс: 1; кадров: 61
    Первый кадр: RMS=0.3535; центроид=1000.02 Гц
    Последний кадр: яркость=0.7071; оттенок=0.2500; масштаб=1.7071

Для сравнения из корня репозитория:

    python3 src/main.py analyze --data src/java/example/input.json --out src/java/output/python.json

Сравниваются ключи, количество кадров и числовые значения с допуском 1e-9. Поле started_at содержит фактическое время запуска.
